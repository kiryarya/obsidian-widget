# Obsidian Memo Widget for Android

このプロジェクトは、Obsidianの[Thino](https://github.com/Quorafind/Obsidian-Thino) (旧 Obsidian Memos) プラグインのように、ホーム画面から素早くメモを登録するためのAndroidウィジェットアプリです。

## 機能

*   **高速起動**: ホーム画面のウィジェットボタンを押すと、即座に軽量な入力ダイアログが開きます。
*   **デイリーノートへの追記**: 選択したフォルダ内の `YYYY-MM-DD.md` ファイルに自動的にメモを追記します。
*   **Thino形式**: `- [HH:mm] メモ内容` という形式で保存されるため、Obsidian内のThinoプラグインと互換性があります。
*   **フォルダ選択**: Storage Access Framework (SAF) を使用して、任意のフォルダ（デイリーノートフォルダなど）を指定できます。

## ビルドとインストール

### 前提条件
*   Android Studio
*   ObsidianでVaultが作成されていること

### 手順
1.  このプロジェクト (`ObsidianMemoWidget`) をAndroid Studioで開きます。
2.  ビルドして実機にインストールします。
3.  アプリを起動し、「デイリーノートフォルダを選択」をタップして、Obsidianのデイリーノートが保存されているフォルダを指定します。
4.  ホーム画面に「クイックメモ」ウィジェットを配置します。

## 使い方
1.  ウィジェットの「＋」アイコンをタップします。
2.  ダイアログが表示されるので、メモを入力します。
3.  「保存」をタップすると、その日のファイル (`2023-10-27.md`など) にメモが追記されます。ファイルが存在しない場合は自動作成されます。

## テストの実行

メモのフォーマットロジックなどのユニットテストが含まれています。Android Studioで `MemoFormatterTest` を実行するか、ターミナルで以下を実行してください：

```bash
./gradlew test
```
